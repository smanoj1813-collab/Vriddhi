# 3.3 Design workflows: Canva, presentations & infographics

> **Lesson plan** · 75 minutes — Read 25 · Lab 40 · Quiz 10

## Learning objectives

By the end of this lesson you will be able to:

- Turn a generated image into a finished, on-brand design using a layout tool's AI features (Canva Magic Studio, Microsoft Designer or Adobe Express).
- Set up a simple brand kit — colours, fonts, logo — and apply it consistently.
- Build a presentation with an AI presentation tool and improve it beyond the default.
- Convert data into a clear infographic or chart, honestly.
- Apply five design fundamentals that separate amateur from acceptable.

## Opening scenario

Two students present the same market survey to the same panel. One has slides generated in thirty seconds: twelve bullet points per slide, a stock-photo background, four fonts. The other spent twenty minutes more: one message per slide, the key number in large type, a single chart per finding, brand colours throughout, a short closing slide with a decision. The panel remembered the second. Design tools with AI make the first kind of deck effortless — and the second kind only slightly harder. The difference is knowing what to ask for.

## Core ideas

### 1. Generation is not design

A generated image is raw material. Design is choosing what goes where, at what size, in what order, so a reader gets the message in three seconds. Layout tools do that job; generators do not. The workflow is:

1. **Brief** (Lesson 3.1) → 2. **Generate** assets (Lesson 3.2) → 3. **Lay out** in a design tool with a brand kit → 4. **Add text** in the design layer → 5. **Export** for the right channel → 6. **Check** on the actual device.

### 2. Design-tool AI features worth learning

Using Canva as the reference (free tier, widely used in Indian colleges and small businesses); Designer and Adobe Express have close equivalents.

| Feature | What it does | Use it for |
| --- | --- | --- |
| **Magic Design / Design from text** | Generates whole layouts (posters, posts, docs) from a description or an uploaded image. | First drafts of posters, social posts, one-pagers. |
| **Magic Media** | Generates images (and short video) inside the canvas. | Fill an illustration slot without leaving the tool. |
| **Magic Edit / Eraser / Expand** | Inpainting, removal, outpainting in-canvas. | Fixes and re-sizing. |
| **Background remover** | One-click cutouts. | Product shots, headshots, layered compositions. |
| **Magic Write** | Text drafting in the design. | Headlines, captions, taglines — then edit in your voice. |
| **Brand Kit** | Saves colours, fonts, logos; applies them across designs. | Consistency. Free tier allows a basic kit. |
| **Resize / Magic Switch** | Converts one design to other formats (post → story → banner → slide). | Repurposing (Lesson 3.5). |
| **Translate** | Translates text layers, including to Kannada, Hindi, Tamil, Telugu. | Bilingual versions of notices and posts. Always proofread. |

### 3. A brand kit in fifteen minutes

Even a club or a family business benefits from three decisions written down:

- **Colours:** one primary, one accent, one neutral. Take them from the logo or the product. Use hex codes ("#0D9488") so every tool matches.
- **Fonts:** one for headings, one for body. Pick fonts that render Kannada/Hindi correctly if you need them (Noto Sans and Noto Serif families are safe and free).
- **Logo:** a clean PNG with transparent background; a light and a dark version.
- **Rules:** minimum logo size, where it sits, photo style (warm, natural, people-focused), tone of captions.

Save these in the tool's brand kit and in a one-page "brand sheet" — you will submit one in Project Block 2.

### 4. AI presentation tools

Tools such as Gamma, Canva Presentations, Microsoft Copilot in PowerPoint, Google's Gemini in Slides and Beautiful.ai draft an entire deck from an outline or a document. They are excellent starting points and mediocre endings. Get more from them with this routine:

1. **Write the story first** in a chat assistant: "Turn this report into a 10-slide narrative: one message per slide, in the order a sceptical manager would want to hear it. Give slide titles as full sentences (the message), not topics."
2. **Generate the deck** from that outline, not from the raw document.
3. **Fix the three usual problems:** too much text per slide (cut to the sentence title plus one visual or three short bullets); generic images (replace with your own generated or real photos); no ending (add a decision or ask slide).
4. **Add the data properly** — a chart per key finding, built from your numbers, not an illustration of a chart.
5. **Speaker notes:** ask the assistant for 40-second notes per slide in your speaking style; rehearse with voice mode (Module 8).

### 5. Data to infographic — honestly

- **Pick the chart for the question:** comparison → bar; trend → line; part of whole → stacked bar or (sparingly) pie; distribution → histogram; relationship → scatter.
- **One chart, one message.** Put the message in the title: "Under-25 walk-ins fell 30% in two years", not "Sales by age group".
- **Build from real numbers.** Paste your table into the design tool's chart feature or into Sheets; never let an image generator draw a chart — it will invent the bars.
- **Do not distort:** axes start at zero for bars; consistent scales; no 3D effects; label units and sources.
- **Infographic layout:** headline → the big number → three supporting visuals → source and date. Ask an assistant: "Turn these five findings into an infographic structure with a headline, hero statistic and three supporting panels; suggest an icon for each panel."

### 6. Five fundamentals that fix most amateur designs

1. **Hierarchy:** the most important element is clearly the largest or boldest. One hero per design.
2. **Alignment:** everything lines up with something. Use the tool's grids and snapping.
3. **Contrast:** dark text on light backgrounds (or the reverse); never text over a busy image without a solid or gradient band.
4. **Proximity:** related items sit together; unrelated items have space between them.
5. **Restraint:** two fonts, three colours, one image style. When in doubt, remove something.

Check every design against these five before exporting. Then check on a phone — that is where most of your audience will see it.

## Try it now

In Canva (or Designer / Express):

1. Open **Magic Design**, upload one image from your Lesson 3.2 set, and describe: *"Instagram post announcing a campus workshop on personal finance for students; friendly, teal and amber palette; space for date and venue."*
2. Pick a result. Replace the headline with your own words. Apply your brand colours. Use **Resize** to make a story version and a WhatsApp square.
3. Ask a chat assistant to critique a screenshot of your design against the five fundamentals. Fix one thing.

## Hands-on lab: from raw assets to a finished set (40 min)

1. **Brand kit (10 min):** create a kit for a real club or business — colours with hex codes, two fonts, logo. Write the four rules.
2. **Poster and post (15 min):** using your Lesson 3.2 images, produce an A4/A3 poster and a 1080×1080 post for the same event. Text added in the design layer; check every letter; apply the kit.
3. **Deck skeleton (10 min):** with an AI presentation tool, generate a 6-slide deck from a sentence-title outline you first drafted with a chat assistant. Replace one generic image and add one real chart.
4. **Fundamentals check (5 min):** score each artefact 1–5 on hierarchy, alignment, contrast, proximity, restraint. Fix the lowest.

**Deliverable:** brand sheet (one page), poster, post, story, six-slide deck (link), and your fundamentals scores. These feed directly into Project Block 2.

## Common mistakes

- **Accepting Magic Design's headline.** Generated text is filler; the message is yours.
- **Text over busy images** with no band behind it.
- **Charts drawn by an image generator.** They are pictures of data that does not exist.
- **Twelve bullets per slide.** One message per slide; the rest goes in notes or a handout.
- **Kannada or Hindi text in a font that cannot render it.** Use Noto fonts and proofread with a native reader.

## Key takeaways

- Generate assets, then design in a layout tool with a brand kit; add text in the design layer.
- Learn the AI features of your design tool: Magic Design, Magic Media, edit/erase/expand, background remover, brand kit, resize, translate.
- AI presentation tools need a sentence-title story first and a fix pass after.
- Charts come from real numbers, chosen for the question, with the message in the title.
- Hierarchy, alignment, contrast, proximity, restraint — then check on a phone.
